# Маленький праздник — сайт-приглашение

Откройте `index.html` двойным щелчком — установка и запуск сервера не нужны.
Фотография находится в `assets/birthday-girl.jpg` и уже подключена.

## Что внутри
- Адаптивное оформление для телефона и компьютера.
- Фото именинницы, воздушные шарики и мягко мерцающие звёзды.
- Конфетти по нажатию и кнопка отключения анимаций; учитывается настройка уменьшения движения в системе.
- Суббота, 5 декабря 2026 года, 13:00–17:00 (UTC+7).
- База отдыха «Притомье», Берёзово, ссылка на поиск места в Яндекс Картах.
- Памятка для бассейна и сауны.
- Обратный отсчёт и скачивание события для календаря.

Кнопка «Ура, идём на день рождения!» запускает конфетти, но не отправляет подтверждение родителям и не собирает персональные данные.
Приглашение на день рождения Николь — 4 года.
Шрифты загружаются из Google Fonts; без интернета используется системный шрифт.

## Как отправить гостям
Разместите `index.html`, `styles.css`, `script.js` и папку `assets` на любом статическом хостинге. Сохраните структуру папок. После размещения гостям можно отправлять ссылку.
Публикация не выполнена автоматически. Учитывайте, что при публичной публикации фото и информация о празднике станут доступны всем, у кого есть ссылка.

## Проверка
`node --check script.js`
`node test.cjs`

Проверяются ссылки на локальные файлы, уникальность идентификаторов HTML, обратный отсчёт, конфетти, переключатель анимаций и календарный файл (часовой пояс, экранирование и длина строк UTF-8).
